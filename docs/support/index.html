Support

Help and contact information for LifeAssist-AI on iPhone and iPad.

Contact support

For help with LifeAssist-AI, email angdembey.dra@gmail.com.

Include your app version, device model, iOS or iPadOS version, and the steps that led to the problem. Please remove personal information from screenshots and do not send passwords, Vault contents, backup files, or unredacted private documents.

Start with one thing

  1. On Home, select a choice, read its highlighted explanation, then tap Continue.
  2. In Add, give the item a title. Category, notes, captures, dates, and reminders are optional. Review and tap Save Item.
  3. Browse My Stuff, review Dashboard or Needs Attention, and use Search to find saved information.

Your selected choice is highlighted and checkmarked. You stay in control of when a workflow starts and when information is saved.

Backup & Restore help

Open LifeAssistAI app Settings menu → 2. Backup & Restore and expand the section. Follow the Backup & Restore user guide for saving, restoring, transferring from a Mac, and checking your restored documents.

Before deleting the app: create a backup, save it outside LifeAssist-AI, and confirm the file exists in Files. Reinstalling alone does not recover local records. Backups are not encrypted and exclude all Private Secure Vault data.

Google Drive “content not available”: a restore problem has been reported even though Drive shows a backup item. That listing alone does not confirm the file can be downloaded. Try downloading or copying the actual backup file into iCloud Drive or On My iPhone, then select that copy in Restore. This workaround still needs confirmation for the reported file. See Google Drive troubleshooting.

If it still fails, contact support with the exact error, whether a backup summary appeared, the file size, and the storage provider. Do not send the backup itself: it contains your saved information and attachments.

Frequently asked questions

Open a question for step-by-step guidance.

Choose an item type, then a category?

Item type describes what you are saving: Appointment, Belonging, Document, or Note. Category describes the kind within that type. Choices are alphabetical; each type has an Other option. Changing type clears a category that no longer fits. Category is optional.

A MacBook Pro fits Belonging → Electronics; a car fits Belonging → Vehicles. Its receipt fits Document → Purchases & receipts, its warranty fits Document → Warranties, its service booking fits Appointment → Vehicle service & inspections, and its service history fits Note → Maintenance notes.

Suggested notes and Voice Input?

Enter a recognizable name, then choose the type and category. Suggested details offer prompts, not facts about your item. Use suggested notes appears only while Notes is empty; once you type or accept voice text, it disappears to protect your writing. Fill only the prompts you need.

Voice Input adds the reviewed transcript to Notes in the current draft. Use Text does not create an item. Review Notes before Save Item. A fresh listening session starts a new transcript. Canceling does not add it. If an old transcript reappears or saved Notes differ, report the steps and app version to Support without sending private content.

Expand only the details you need?

Add keeps optional information in collapsible sections. Item Details groups Item information, Notes, Dates, Attachments, Saved codes, Reminders, and More actions. Expand a section to view or edit; Save item changes when finished.

Added badges and summaries identify saved content. Empty sections show Add details or an empty-state message; expand these to add information. Loading and Needs attention have separate states. Attachment and code actions share compact rows and wrap when screen width or larger text needs more space. Archived items show read-only contents.

Dates and reminders for this item?

Due / event means when this item needs action or an appointment happens. Expiry / warranty end means when the document, coverage, membership, or warranty ends. Enter only dates that apply. Date and optional time share a row; expiry has its own row.

Choose Remind me and Before which date? to identify the date being counted back from. Lead times include 1, 2, or 3 months before, using calendar months and the last valid day for shorter months. Due / event alerts use your chosen time, or 9:00 AM locally; expiry alerts use 9:00 AM. The resulting alert must be in the future. In Item Details → Reminders, review scheduled reminders or create an alert with its own future date and time.

Typing on iPhone or iPad?

Forms scroll above the keyboard so the focused entry remains reachable. Scroll within long Notes to reach more lines; use Done where offered to dismiss the keyboard, or drag the form to dismiss it.

If the keyboard still covers the cursor, contact Support with the screen name, device, app version, and text-size setting. Avoid including private notes in screenshots.

How do the Home choices work?

Choose Add Something, Capture Something, Voice Input, or Private Secure Vault. A checkmark and highlighted row show the selection; the highlighted message explains it. Choosing a row does not start the workflow. Tap Continue when ready. Mouse or trackpad hover and keyboard focus also show hints.

How do I add an item in a category?

In My Stuff, select a category such as Vehicles, then tap the Add tab. That category is preselected in Add. An empty active category also offers Add an item with the same category preselected. You can change it before saving. All does not force a category; Uncategorized chooses no category. Other draft fields stay available.

Where are the other categories?

Swipe the category strip horizontally. More › appears when categories are hidden to the right; ‹ More appears when there are categories to the left. Tap either to scroll without changing your selection. Scroll vertically to see saved items and their information.

How do I return without saving?

On an existing item, Back returns to the screen you opened it from. Unsaved item edits prompt you to keep editing or discard them. On Add, Back returns to the previous tab without saving, and keeps your draft available. Saving a new item opens its details.

How do I capture a document, photo, file, or code?

Choose a capture method in Add or Home → Capture Something. Review Preview → Use in this item, then Save Item in Add. The capture and accepted voice Notes save together as one item. Add stages one capture at a time; add more through Item Details after saving. Canceling acquisition preserves other draft fields.

Where did my captured document go?

Use in this item stages a capture; Save Item finishes saving the new item. Open My Stuff → All and check Active and Archived, or Search by title. Expand Attachments or Saved codes on the item. Captures added to an existing active item stay with that item. Vault documents are separate and excluded from Search and app backups. Records do not automatically sync between devices.

What happens when I cancel QR-code capture?

Cancel or return from the QR/barcode scanner takes you back to the Capture page so you can choose another method. Canceling does not create a saved record.

How does Voice Input work?

Choose Voice Input on Home and Continue, or use Voice Input beside Notes in Add. Allow Microphone and Speech Recognition access, start listening, then review the transcript. Use Text adds reviewed words to Notes; it does not save an item or execute spoken commands. Save Item when ready. On-device recognition depends on the device and language; typing remains available.

Where are passwords and other private records?

Open Home → Private Secure Vault → Continue. Set a device passcode first, then unlock with Face ID, Touch ID where supported, or your device passcode. Choose Secure Password Management, Secure Documents, Secure Note/Code, or Other Secure Stuffs. The Vault locks when you leave or switch away. Private records are excluded from ordinary Search and Backup & Restore. Keep a separate safe copy of important Vault information; reinstalling is not a recovery method.

Why did Search match this word?

Search is case-insensitive. One or two letters or digits match whole words: CA does not match card. Use three or more characters for partial matches: car can match card, and the matching word is highlighted in the result. Search covers ordinary saved item information, attachment names, saved text, and captured codes. Expand attachment/code groups to see their matches. Tap an item’s name or summary for details; attachment matches open the matching attachment.

Private Secure Vault records are not included in Search. Open and unlock the Vault to view passwords, private documents, notes/codes, and other secure records.

How do I work with attachments and saved codes?

In Item Details, check one attachment or code. Its information and available actions appear below the choices, instead of repeating actions for every entry. View, share, print, extract text, open a URL, or delete when supported for that selected entry. Swipe the choices or tap More to reveal hidden entries. Category choices also scroll horizontally. Deleting asks for confirmation.

How do I use the compact Vault lists?

Choose a Vault section, then check a record in its numbered list. Its details and available actions appear below. Passwords and secure note contents stay hidden until you explicitly choose View / edit. Secure documents offer View, Share, and Print. Sharing or printing warns that a copy will leave the Vault; the receiving destination controls that copy.

Tap Privacy, recording, and recovery details to expand the full explanation. App-switcher previews are protected. Screenshots, recording, and mirroring are not blocked on iPhone; stop recording or mirroring before opening private information.

What do Home and Dashboard show?

Home shows Needs Attention and a compact Recent list. Dashboard provides an overview of items, categories, reminders, and dates. Tap a saved item to open its details. My Stuff lets you browse Active or Archived items and filter by category.

How do I use the compact Settings page?

Open the LifeAssistAI app Settings gear. Tap a numbered section to expand or collapse its controls. Expand all and Collapse all remain at the top while you scroll. The main backup warning remains visible; expand Protect your saved information for the full explanation. In Appearance, choose System, Light, or Dark. In Color Theme, choose Classic, Soft Blue, Soft Green, Warm, or Lavender. Text follows the device text-size setting. Website appearance is a separate preference.

Do I need an account or internet connection?

No account is required. Core organization, local reminders, saved-file access, scanning, and text extraction work on your device. A cloud file provider, website, online sharing destination, or these support pages may require internet access.

Why am I not receiving reminders?

Check device Settings → Notifications → LifeAssist-AI and allow notifications. Also check Focus, notification delivery settings, and the reminder date and time. Reminder records remain visible in the app even if alerts are disabled. Alerts do not automatically complete reminders; review, complete, or reschedule them in the app.

Why does text extraction miss some text?

Use a clear, well-lit image with readable text. Check recognized text against the original. Imported PDFs need embedded text for PDF text extraction. An image-only imported PDF may return no text; scan the original or import its pages as images for image recognition.

Can I share or print documents?

Open a supported saved attachment or its extracted text and choose Share or Print. Sharing uses the destination you select. Printing opens the system print sheet and needs a compatible available printer. Not every file format supports preview or printing. Canceling leaves the saved attachment in place.

Are my records backed up or synchronized?

Backups are manual: LifeAssistAI app Settings menu → 2. Backup & Restore → Create backup / Save to Files. Save the JSON file outside this app and verify it in Files. There is no automatic backup or cloud sync. Backups include ordinary active and archived items and their attachments, but exclude all Private Secure Vault data. Files are not encrypted; maximum backup size is 100 MB. Read the complete guide.

Where can I save and restore a backup?

iCloud Drive and On My iPhone backup and restore have been verified on an iPhone. Use a folder outside LifeAssist-AI’s own storage. An On My iPhone copy stays on that device; keep another copy elsewhere against device loss. Restore uses the Files picker: select the actual LifeAssist-Backup-….json file, review its date and counts, then choose Restore missing items and confirm Restore.

Why does Google Drive say content is not available?

This restore issue has been reported and remains unresolved. A visible folder item may not yet be available to the Files picker. Sign in to Drive, check your connection, and try downloading or copying the actual JSON backup to iCloud Drive or On My iPhone before restoring. Do not choose the folder or a shortcut. See troubleshooting steps; this is a suggested workaround, not a confirmed fix.

Can I restore a backup saved on my Mac?

The iPhone picker cannot browse your Mac directly. Put the backup in iCloud Drive and wait for it to become available on the iPhone, or AirDrop it to the iPhone and save it in Files. Then choose that JSON file using Choose backup to restore. See the Mac transfer instructions.

Will restore replace my records or bring back reminder alerts?

Restore adds missing items and keeps existing items with the same internal ID, including their attachments, unchanged. Repeated imports of the same backup skip those existing items. Separately created items with the same title may both appear. Archived items stay archived. Reminder records return, but notification alerts must be recreated in Item Details. Vault records and app appearance settings are not included.

How do I remove stored information?

Archive keeps a record indefinitely on this device. In My Stuff → Archived, choose Restore to make it active again; an Item restored message confirms success. Archived items are read only. Delete permanently removes one selected archived item and its notes, attachments, saved codes, extracted text and suggestions, and reminders. There is no Undo. Check the item name before confirming. Choose Back up first to open the LifeAssistAI app Settings menu → Backup & Restore → Create backup / Save to Files. Verify the external backup before deletion. Old backups, shared copies, original Photos/Files, and Vault records remain separate. Retry cleanup handles unfinished file or notification cleanup.

Does this version include cloud AI?

This release uses on-device text recognition, supported on-device speech recognition, and local search. It does not include live AI chat or cloud document analysis. Capturing a QR code or barcode does not automatically open a web link.
